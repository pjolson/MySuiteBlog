# ITM-13 expansion: local acceptance

Expanded existing ITM-13 locally. No deployment, commit, push, NetSuite account access or import test. Catalogue remains 118 entries and 35 guides.

## Baseline and implementation

Previously the full wording selected a matrix-specific entry, the partial wording produced an ambiguous parent/matrix group, and RCRD_NOT_FOUND had no result. ITM-13 now has the general record-identity title and explanation, ordinary Inventory Item + Update checks, and four unselected identifier follow-up choices. The documented matrix correction remains conditional. Chart of Accounts and Vendor-Subsidiary Relationship use the existing import selector to expose their own checks. The shared page introduction was broadened while retaining its existing slug and all entry anchors.

Both searches use the same entry and distinctive phrase/code rule. Message matches identify wording, not a confirmed cause. Related links cover record-type mismatch, context-specific item references, spreadsheet conversion and conditional script investigation. Update is distinguished from Add or Update. Names, internal IDs, external IDs and related-field references remain separate.
